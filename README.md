# 우리 앨범

초대된 가족과 지인이 로그인해 사진과 영상을 함께 올리고, 업로드한 날짜별로 보는 Spring Boot 웹앱입니다.

## 기능

- 관리자 계정은 첫 실행 때 `ADMIN_EMAIL`, `ADMIN_PASSWORD` 환경 변수로 등록합니다.
- 관리자만 일회용 초대 코드를 발급할 수 있습니다. 발급된 코드는 화면에 한 번만 보여줍니다.
- 초대 코드로 가입한 사용자는 관리자와 같은 업로드·열람 권한을 가집니다.
- 사진과 영상은 한국 시간 기준 업로드 날짜별로 모입니다.
- 파일과 앨범은 로그인한 사용자에게만 공개됩니다. 사진은 JPG, PNG, WebP, GIF, 영상은 MP4, WebM, MOV를 지원하며 파일당 최대 25MB입니다.

## 로컬 실행

Java 21 이상이 필요합니다. Maven Wrapper가 Maven 3.9.9를 프로젝트 내부 캐시에 자동으로 준비합니다. 처음 실행할 때 Maven 배포 파일을 내려받으므로 네트워크 연결이 필요합니다.

```bash
./mvnw spring-boot:run
```

로컬 실행은 H2에 `admin@localhost` 관리자 계정을 저장합니다. `ADMIN_PASSWORD`를 설정하지 않으면 매번 시작할 때 새 비밀번호를 만들고 로그에 표시합니다. 이전 로컬 관리자 비밀번호는 다음 재시작부터 사용할 수 없습니다. 재시작 뒤에도 비밀번호를 유지하려면 실행 전에 `ADMIN_EMAIL`과 10자 이상의 `ADMIN_PASSWORD`를 설정하세요.

브라우저에서 `http://localhost:8080`을 열어 로그인합니다. 앱은 프로젝트 루트에 H2 데이터베이스 파일을 만들고 `./uploads`에 파일을 저장합니다. 경로는 각각 `DB_PATH`, `UPLOAD_DIR` 환경 변수로 변경할 수 있습니다.

## 테스트

기능을 추가하거나 바꿀 때는 먼저 기대 동작을 테스트로 작성하고, 해당 테스트를 실행해 실패하는 것을 확인한 뒤 구현합니다.

```bash
./mvnw test
```

실행 가능한 JAR 파일은 `./mvnw package`로 `target/`에 생성됩니다.

## 배포 참고

Render에 배포할 때는 코드를 비공개 GitHub 저장소에 올린 다음 Render Dashboard에서 **New → Blueprint**를 선택하고 이 저장소를 연결합니다. 저장소 루트의 `render.yaml`을 읽어 서비스 구성을 만들며, 첫 생성 과정에서 관리자 `ADMIN_EMAIL`과 10자 이상의 `ADMIN_PASSWORD`를 입력합니다. 서비스는 Render가 발급하는 `onrender.com` HTTPS 주소로 제공됩니다.

무료 서비스는 일정 시간 요청이 없으면 잠들 수 있고, 다시 접속할 때 깨어나는 시간이 필요합니다. 현재 H2 데이터베이스와 업로드 파일은 컨테이너 로컬 디스크에 저장되므로 인스턴스가 재시작되거나 다시 배포되면 사라질 수 있습니다. 이 동작은 현재 개인 테스트 용도로 감수하기로 한 조건입니다.
